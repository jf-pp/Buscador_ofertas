# Prompt: agregar una tienda

Quiero agregar la tienda [nombre y URL] como fuente de precios en este proyecto.

1. Lee `docs/VERIFICATION-RULES.md` y `docs/ARCHITECTURE.md`.
2. Explica cómo verificar un precio ahí: ¿tiene API pública, se puede leer la ficha directo, o solo verificación manual?
3. Si tiene API pública, propón cómo integrarla sin añadir dependencias. Si no, propón solo el flujo manual (anotar fuente, fecha y verificado).
4. No inventes precios de esa tienda: usa solo lo que se pueda verificar.

Entrega el cambio en la spec que corresponda y el código mínimo.
